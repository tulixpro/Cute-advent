# Kleine Jahreszeiten-Magie

Eine kostenlose, statische Jahreszeiten-Countdown-Seite mit HTML, CSS und Vanilla JavaScript. Es werden keine externen APIs, Bibliotheken oder kostenpflichtigen Assets verwendet.

Nachts erscheinen eine sanft eingeblendete Winter-Bergkulisse und ein Sternenhimmel. Über den Knopf **Ins Haus gehen** kannst du das Wohnzimmer besuchen, das Schlitten-Minispiel spielen und im Advent die Tages-Türchen öffnen.

## Lokal öffnen

`index.html` direkt im Browser öffnen. Für lokale Tests kann die Seite auch von einem beliebigen statischen HTTP-Server bereitgestellt werden.

## Auf GitHub Pages veröffentlichen

Der Workflow unter `.github/workflows/pages.yml` veröffentlicht die Seite automatisch, wenn Änderungen nach `main` gepusht werden. Er kann außerdem im Tab **Actions** manuell gestartet werden. GitHub Pages ist für dieses Repository bereits auf **GitHub Actions** eingestellt.

Wenn du das Projekt in ein anderes Repository kopierst, wähle dort einmal unter **Settings → Pages** als Build and deployment source **GitHub Actions** aus. Die Seite ist unter folgender Adresse erreichbar:

<https://tulixpro.github.io/Cute-advent/>

Die Veröffentlichung benötigt weder einen Build-Schritt noch zusätzliche Projekt-Abhängigkeiten.
